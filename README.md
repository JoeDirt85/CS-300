# CS-300
Repository for class projects for the term

# What was the problem you were solving in the projects for this course?
  Throughout the course, we worked with various data structures and the methods to store information within them. Each week we worked with a single structure 
  and learned how to implement differenet fucntions to insert, search and print specific or all items stored within. We went over data stuctures such as vectors, linked lists, hash maps and binary search trees. 
  Diving into their differences and time complexeties, to determine when one is best utilized. 

# How did you approach the problem? Consider why data structures are important to understand.
  To approach this problem, I tried to obsord as much information of each data structure that I could, and the different algorithms that
  could be applied to them. I would then use this information during the assignments to as a reference in my work, to be able to complete 
  the programs we were tasked to finish. 

# How did you overcome any roadblocks you encountered while going through the activities or project?
  During this process, I faced my fair share of roadblocks, often times struggling to properly implement my code to do what I had intended.
  To overcome this, I would spend some time going over the material or searching for other material that I could read, to help me figure out where I
  was going wrong in my code.

# How has your work on this project expanded your approach to designing software and developing programs?
  It has helped me think more about how to solve my problems in a more effiecent way. Before, I think often times, I would go the route of 'Brute Force,'
  and using a program that does more work to find a simple result. 

# How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
  I have started to really add more programmer comments, that say what the program is intended to do, so that if anyone else or even I goes back through, 
  will know why things are there. It has also helped me to utilize the use of classes and methods, so that I can easily call a function in different areas rather than rewriting 
  countless lines of code to achieve the same outcome.
